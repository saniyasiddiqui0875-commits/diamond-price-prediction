# 💎 Diamond Price Prediction

## 📌 Project Overview

An end-to-end Machine Learning project that predicts diamond prices based on their physical and quality characteristics.

The project includes data preprocessing, model comparison, prediction and an interactive Streamlit application.

---

## 🚀 Features

- Diamond price prediction
- Data preprocessing and analysis
- Multiple regression models
- Interactive Streamlit prediction interface
- Dataset visualization
- Model performance comparison

---

## 📊 Dataset

The dataset contains **53,920 diamond records**.

### Features

- Carat
- Cut
- Color
- Clarity
- Depth
- Table
- X
- Y
- Z

### Target

**Price**

---

## 🤖 Machine Learning Models

The following models were evaluated:

- Linear Regression
- Decision Tree Regressor
- Random Forest Regressor

### Best Model

**Random Forest Regressor**

R² Score: **0.999971**

## 📈 What the Application Does

The application allows users to:

1. Enter diamond characteristics.
2. Generate a predicted diamond price.
3. Explore the diamond dataset.
4. Visualize the distribution of diamond prices.
5. Analyse relationships between diamond characteristics and price.
